# TrendWala Tools

Free online tools for images, PDFs, text, JSON, Base64, URLs and QR codes.

🌐 **Live Website:** https://tools.trendwala.in/

## Features

- HEIC to JPG, PNG and WebP conversion
- JPG, PNG and WebP conversion
- Image compression, resizing, cropping and rotation
- Image to PDF conversion
- PDF merge, split, rotation and PDF to JPG
- Word and character counters
- Case converter and text cleaning tools
- JSON formatter and validator
- Base64 encoder and decoder
- URL encoder and decoder
- QR code generator

## Privacy First

TrendWala Tools is designed for browser-side processing wherever possible. Your files do not need to be uploaded to a server for the supported tools.
